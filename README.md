# C-sharp-and-.Net-Framework
These are some small projects I made using C# and ASP.NET MVC.

## Projects:
- Car Insurance
- TechStore Inventory
- Newsletter SignUp

## Car Insurance
This project is an ASP.NET Core MVC web application that mimics a car insurance website. It takes user's input on policy information and calculates a quote based on business logic. There is also an admin page that allows staff to view all of the quotes that have been issued.

## TechStore Inventory
This is a data management application that is meant to store and display product inventory data for a technology retail store. It is an ASP.NET Core MVC web application that utilizes Entity Framework Core for data access.It implements CRUD operations on the database using C#.

## Newsletter SignUP
This is a web application built with the .NET Framework MVC framework. It includes functions for adding and querying users, allowing administrators to create newsletter content and maintain subscriber lists.
